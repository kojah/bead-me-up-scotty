# Scotty v0.3.0 — Clearer Board drag and drop

## What's changed

- Dragged Board cards now follow the pointer across columns with a floating preview.
- Valid destination columns highlight while hovering cards or empty space, including the bottom of shorter columns.
- Pointer-based targeting makes cross-column drops land in the intended column while preserving manual ordering.
- Cancellation clears the preview and highlight without writing changes. Dependency-blocked cards no longer advertise a Ready move when the status would remain unchanged.
- The drag preview has no duplicate focusable copy button.
- Fixed the approval regression test to recognize the Needs You button when its count badge is present.
- Includes the post-v0.2.0 fix enabling configured usage reporting for fresh installations and retrying failed delivery; the existing opt-out remains available.

Thanks to @bourke for the Board drag-and-drop contribution in #58.

## Install this release

Prerequisites: a supported Node.js version (Node 20.9+; Node 22 or newer recommended), npm, and the Beads `bd` CLI for live project data. Without `bd`, Scotty can run with demo data.

```sh
git clone --branch v0.3.0 https://github.com/brendan-appstart/bead-me-up-scotty.git
cd bead-me-up-scotty
npm ci
npm run build
npm run serve
```

Open `http://localhost:3000`. This checks out the release tag; a detached checkout is expected and supported by the stable updater. The supervised launcher restarts automatically after a successful in-app update.

For a global `scotty` command, follow the README's `npm link` or global-copy instructions after building this release. This release does not publish a package to the npm registry or include a desktop installer.

## Update an existing installation

**Existing Git checkout:** existing versions may only know about main. To install this exact release, first commit or stash local source changes, then run from the app's checkout:

```sh
git fetch origin tag v0.3.0
git merge --ff-only 'v0.3.0^{commit}'
npm ci
npm run build
```

Restart Scotty. If Git refuses the fast-forward, preserve your work and use a separate release checkout rather than resetting your branch. Once on v0.3.0, later published versions appear through the stable update channel.

**Global copy or source download:** build a fresh checkout of the chosen release using the install steps, then repeat `npm install -g .` for a global copy, or replace the source installation. Restart Scotty. The in-app notice links to these instructions; it does not attempt a Git update in a non-Git installation.

**Docker:** rebuild the image from the release source and recreate the container using your existing configuration and persistent mounts. The in-app update notice is informational; update the image through your Docker workflow. See the README for container setup.

The update feature updates Scotty's source and dependencies, not your Beads issue database. Back up your local project data as usual.

## Scope and validation

This is a source release, with installation through Git/source or Docker. It does not publish an npm package or a desktop installer. Beads data stays local and is not modified by the release process.

Validation uses an isolated demo server, intercepted browser fixtures, and disposable test repositories. All 27 regression scripts passed, including Board sorting and drag feedback, approval, keyboard navigation, read-only guards, telemetry, and update flows. The production build and TypeScript checks passed. Lint reported no errors and one existing navigation warning in `hooks/use-notifications.ts`. The dependency audit reported zero vulnerabilities.
